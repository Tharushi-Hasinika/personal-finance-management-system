# Project Objectives
## Personal Finance Management System

### 1. Main Objective

The main objective of this project is to design and develop a centralized personal finance management system that enables individuals to efficiently record, organize, monitor, and analyze their financial activities through synchronized web and mobile applications.

### 2. Specific Objectives

The project aims to achieve the following specific objectives.

#### 2.1 Develop a Centralized Financial Management Platform

- Develop a centralized application for maintaining personal financial information.
- Provide a structured approach to organizing financial records.
- Allow users to access their financial information through web and mobile platforms.

#### 2.2 Implement Account and Wallet Management

- Provide facilities to create and manage multiple financial accounts and wallets.
- Maintain separate balances for bank accounts and physical cash.
- Support internal transfers between personal financial sources.
- Maintain accurate transaction histories for each account and wallet.

#### 2.3 Simplify Income and Expense Tracking

- Allow users to record income and expenses manually.
- Provide transaction categorization facilities.
- Associate transactions with relevant financial accounts or wallets.
- Provide access to historical transaction records.

#### 2.4 Implement Daily Budget Management

- Allow users to define and maintain daily food budgets.
- Support separate recording of breakfast, lunch, and dinner expenses.
- Automatically calculate remaining daily budget amounts.
- Record unspent food budget amounts as savings.
- Support the management of situations where daily expenses exceed the allocated budget.

#### 2.5 Provide Savings Management

- Maintain separate savings records.
- Track savings accumulated over time.
- Record additions and withdrawals from savings.
- Provide information about historical savings activities.

#### 2.6 Implement Lending Management

- Allow users to record money lent to other individuals.
- Maintain records of outstanding lending amounts.
- Support full and partial repayment recording.
- Provide repayment histories and outstanding balance information.

#### 2.7 Develop Financial Reporting and Analytics

- Generate monthly financial summaries.
- Present income and expense breakdowns.
- Provide information about account and wallet balances.
- Analyze daily food expenditure and accumulated savings.
- Display outstanding lending amounts and repayment information.
- Present financial information through suitable charts and visualizations.

#### 2.8 Implement Secure Authentication and Authorization

- Provide user registration and login facilities.
- Implement secure authentication mechanisms.
- Ensure that users can access only their own financial information.
- Protect sensitive financial data through appropriate security measures.

#### 2.9 Support Multi-Device Synchronization

- Develop a web application and a mobile application.
- Provide a centralized backend for managing financial information.
- Synchronize financial records across supported devices.
- Maintain consistency when financial information is updated from different devices.

#### 2.10 Apply Modern Software Engineering Practices

- Design the backend using microservices architecture.
- Implement layered architecture within individual backend services.
- Develop RESTful APIs for communication between system components.
- Apply relational database design principles.
- Use Docker for application containerization.
- Explore Kubernetes for container orchestration and deployment.
- Apply software testing, version control, and documentation practices throughout development.

### 3. Expected Achievements

Upon successful completion, the project is expected to deliver:

- A functional personal finance management platform.
- Web and mobile applications with synchronized financial records.
- Reliable management of accounts, wallets, income, and expenses.
- Daily budget and savings tracking facilities.
- Lending and repayment management.
- Financial summaries and analytical reports.
- A maintainable backend developed using modern software engineering technologies.
